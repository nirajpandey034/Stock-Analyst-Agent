# Financial Research Agent

An AI-powered Financial Research Agent built with TypeScript that leverages LLM tool calling, real-time financial APIs, and structured output validation to perform stock research and investment analysis.

The agent can autonomously:

- Discover stock ticker symbols
- Fetch company financial data
- Reason over retrieved information
- Generate investment recommendations
- Validate responses using Zod schemas


---

## Environment Variables

Create a `.env` file in the project root:

```env
# AI Provider
BASE_URL=https://api.groq.com/openai/v1

# Groq
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL_1=llama-3.3-70b-versatile

# OpenRouter (Optional)
OPENROUTER_API_KEY=your_openrouter_api_key
OPENROUTER_MODEL_1=model_name

# Financial Modeling Prep
FINANCIAL_MODEL_API_KEY=your_fmp_api_key
FINANCIAL_MODEL_URL=https://financialmodelingprep.com/stable/
```

## Available Tools

### getTickerSymbol

Finds a stock ticker symbol using a company name and currency.

#### Input

```json
{
  "companyName": "TATA Motors",
  "currency": "INR"
}
```

#### Output

```json
{
  "data": [
    {
      "symbol": "TATAMOTORS.NS"
    }
  ]
}
```

---

### getCompanyFinancials

Retrieves company profile and financial details using a ticker symbol.

#### Input

```json
{
  "ticker": "TATAMOTORS.NS"
}
```

#### Output

```json
{
  "companyName": "Tata Motors Limited",
  "price": 339.8,
  "marketCap": 1251256200545
}
```

## Structured Output Validation

Responses generated by the LLM are validated using Zod.

### Schema

```typescript
{
  company: string;
  recommendation: "BUY" | "SELL" | "HOLD";
  risk: "LOW" | "MEDIUM" | "HIGH";
  strengths: string[];
  weaknesses: string[];
}
```

### Validation Flow

```text
LLM Response
      ↓
JSON Parse
      ↓
Zod Validation
      ↓
Validated Output
```
